# 🎣 ماهیگیری جدول ضرب

بازی آموزشی اندروید برای تمرین جدول ضرب با فضای دریایی، سؤال‌های چندگزینه‌ای و پیشرفت مرحله‌ای. پاسخ‌ها با لمس گزینه انتخاب می‌شوند؛ نیازی به تایپ عدد نیست.

## امکانات

- بازی تمام‌صفحه با فضای دریایی و انیمیشن
- ۱۰ فصل با سختی تدریجی
- تمرین تطبیقی بر اساس پاسخ‌های قبلی
- گزارش پیشرفت جدول‌های ضرب ۱ تا ۱۲
- ذخیره پیشرفت روی دستگاه و امکان بازی آفلاین
- موسیقی، دستاوردها و آکواریوم شخصی
- فصل‌های ۱ تا ۴ رایگان؛ بازکردن دائمی فصل‌های ۵ تا ۱۰ از طریق پرداخت درون‌برنامه‌ای بازار

## اجرای پروژه

نیازمندی‌ها: Node.js 22 و npm.

```bash
npm ci
npm run dev
```

## بررسی کیفیت

قبل از انتشار، این فرمان باید بدون خطا تمام شود:

```bash
npm run verify
```

این فرمان شامل بررسی TypeScript، تست‌های واحد و build وب است.

## ساخت نسخه اندروید

```bash
npm run android:debug
npm run android:release
```

ساخت Release به تنظیمات امضای انتشار و کلید عمومی پرداخت بازار در محیط ساخت نیاز دارد. راهنمای انتشار و تنظیمات محرمانه در [راهنمای انتشار](STORE_RELEASE.md) و [راهنمای پرداخت بازار](BAZAAR_BILLING_SETUP.md) آمده است. کلیدها و فایل keystore را هرگز در مخزن commit نکنید.

در GitHub Actions، workflow ساخت اندروید برای بررسی PR نسخه Debug تولید می‌کند. برای نسخه قابل انتشار، workflow را از بخش Actions طبق راهنمای انتشار اجرا کنید و artifact نسخه Release را دریافت کنید. پیش از بارگذاری در بازار، APK را روی دستگاه واقعی نصب و آزمایش کنید.
