# 🎣 بازی ماهیگیری جدول ضرب

یک بازی آموزشی تحت وب و اندروید برای کودکان با تم ماهیگیری که تمرین جدول ضرب را به یک ماجراجویی سرگرم‌کننده تبدیل می‌کند.

**نسخه:** 1.0.0  
**Package:** `com.arsha.fishmath`  
**وضعیت:** آماده انتشار در گوگل‌پلی

---

## 🚀 شروع سریع (وب)

```bash
npm install
npm run dev
```

## 📱 بیلد اندروید

```bash
# همگام‌سازی و بیلد دیباگ
npm run android:debug

# APK انتشار (نیاز به keystore)
npm run android:release

# AAB برای گوگل‌پلی (توصیه می‌شود)
npm run android:bundle
```

راهنمای کامل انتشار: **[STORE_RELEASE.md](STORE_RELEASE.md)**  
سیاست حریم خصوصی: **[PRIVACY_POLICY.md](PRIVACY_POLICY.md)**
