# 🎣 بازی ماهیگیری جدول ضرب

یک بازی آموزشی تمام‌صفحه برای کودکان با تم ماهیگیری که تمرین جدول ضرب را به یک ماجراجویی سرگرم‌کننده تبدیل می‌کند. کودک جواب را تایپ نمی‌کند؛ همیشه از بین گزینه‌ها انتخاب می‌کند.

**نسخه:** 1.2.0  
**Package:** `com.arsha.fishmath`

---

## 🚀 شروع سریع (وب)

```bash
npm install
npm run dev
```

## 📱 بیلد اندروید

```bash
npm run android:debug
npm run android:release
npm run android:bundle
```

## 🎮 ویژگی‌های بازی

- تجربه تمام‌صفحه با اقیانوس زنده در پس‌زمینه
- پاسخ فقط با لمس گزینه (بدون کیپد و بدون تایپ)
- ۱۰ فصل با سختی پیشرونده و فصل‌های بصری
- کوسه‌خالخالی بامزه، سیستم باس، قدرت‌های ویژه
- دستاوردها، آکواریوم شخصی، موسیقی ملایم
- انتخاب تطبیقی سؤال‌ها بر اساس نقاط ضعف
- صفحه پیشرفت یادگیری برای جدول‌های ×1 تا ×12
- کاملاً آفلاین و مناسب کودکان
