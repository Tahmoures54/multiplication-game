# 🎣 ماهیگیری جدول ضرب

بازی آموزشی اندروید برای تمرین جدول ضرب در یک دنیای دریایی؛ کودک پاسخ‌ها را با لمس گزینه‌ها انتخاب می‌کند و نیازی به تایپ عدد ندارد.

## امکانات

- بازی تمام‌صفحه با فضای دریایی و انیمیشن
- ۱۰ فصل با سختی تدریجی
- تمرین تطبیقی بر اساس پاسخ‌های قبلی
- گزارش پیشرفت جدول‌های ضرب ۱ تا ۱۲
- ذخیره پیشرفت روی دستگاه و امکان بازی آفلاین
- موسیقی، دستاوردها و آکواریوم شخصی
- فصل‌های ۱ تا ۴ رایگان؛ بازکردن دائمی فصل‌های ۵ تا ۱۰ از طریق خرید درون‌برنامه‌ای کافه‌بازار
- پیش از آغاز خرید، یک پرسش تأیید بزرگسال نمایش داده می‌شود. این یک مانع ساده رابط کاربری است، نه احراز هویت قطعی والدین.

## فناوری و اجرای محلی

- React 19، TypeScript، Vite و Capacitor 6
- Node.js 22 و npm

```bash
npm ci
npm run dev
```

## بررسی کیفیت

قبل از انتشار اجرا کنید:

```bash
npm run verify
```

این فرمان شامل بررسی TypeScript، تست‌های واحد و build وب است. برای ساخت اندروید:

```bash
npm run android:debug
npm run android:release
npm run android:bundle
```

ساخت Release محلی نیازمند تنظیمات امضای انتشار و کلید عمومی پرداخت بازار است.

## انتشار در کافه‌بازار

1. در GitHub به **Settings → Secrets and variables → Actions** بروید و اسرار زیر را تنظیم کنید:
   - `RELEASE_KEYSTORE_BASE64`
   - `RELEASE_KEYSTORE_PASSWORD`
   - `RELEASE_KEY_ALIAS`
   - `RELEASE_KEY_PASSWORD`
   - `BAZAAR_RSA_PUBLIC_KEY`
2. در بخش **Actions**، workflow ساخت اندروید را اجرا کنید و مسیر Release را انتخاب کنید. پس از موفقیت کامل، artifact نسخه Release را دریافت کنید. برای انتشار در بازار از APK امضاشده استفاده کنید، مگر آنکه پنل بازار قالب دیگری بخواهد.
3. پیش از بارگذاری، APK را روی گوشی واقعی نصب و آزمایش کنید. موفقیت CI به‌تنهایی جایگزین آزمون دستگاه و پرداخت واقعی نیست.

**مهم:** فایل keystore، رمزها و کلیدهای خصوصی را هرگز در مخزن، کد منبع یا لاگ‌ها قرار ندهید. برای به‌روزرسانی‌های آینده همان کلید امضای قبلی را نگه دارید.

### پرداخت درون‌برنامه‌ای

- شناسه محصول: `fishmath_full_unlock`
- نوع محصول در پنل بازار: خرید یک‌باره / غیرمصرفی
- خرید، فصل‌های ۵ تا ۱۰ را برای همیشه باز می‌کند؛ فصل‌های ۱ تا ۴ رایگان‌اند.
- محصول دائمی نباید مصرف (consume) شود.
- خرید با کلید عمومی RSA مخصوص همین برنامه اعتبارسنجی می‌شود و وضعیت خرید تأییدشده روی دستگاه نگه‌داری می‌شود. برنامه سرور اختصاصی ندارد؛ بنابراین وضعیت محلی آفلاین در برابر دست‌کاری به اندازه تأیید سمت سرور مقاوم نیست.
- در صورت نامشخص بودن نتیجه پرداخت، ابتدا بازیابی خرید را امتحان کنید و از پرداخت دوباره تا روشن‌شدن وضعیت خودداری کنید.
- پرسش تأیید بزرگسال صرفاً یک مانع رابط کاربری است و جایگزین کنترل والدین در سطح سیستم یا احراز هویت نیست.
